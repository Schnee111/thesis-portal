# Portal Review Tesis

Portal dokumentasi aktif Systematic Literature Review tesis Ilmu Komputer UPI tentang selective approval gate orkestrasi multi-agent hierarkis. Status: M1 LOCKED, M2 FROZEN, M3 L1 DONE, L2 OPEN. Angka korpus hanya di [Progres](progres.md).

---

## Glosarium

| Istilah | Definisi singkat |
|:---|:---|
| PICOC | Kerangka Population, Intervention, Comparison, Outcome, Context untuk pertanyaan riset. |
| QGS-6 | Enam paper quasi-gold untuk uji recall query. |
| DEF | Formulir ekstraksi data tiap studi primer. |
| PRISMA 2020 | Alur pelaporan seleksi studi sistematis. |
| IC/EC | Kriteria inklusi dan eksklusi seleksi naskah. |
| Kappa | Indeks kesepakatan antar-penilai pilot L2. |

---

## Cara pakai (3 langkah)

1. **Periksa protokol dan kueri.** Buka [Perencanaan](perencanaan.md) untuk PICOC, search string, kriteria IC/EC, instrumen QA, dan status sumber.
2. **Pantau progres dan diagram PRISMA.** Buka [Progres](progres.md) untuk angka korpus, diagram alir, bukti recall, retrieval, recovery, dan Tier-3.
3. **Tinjau matriks kalibrasi dan referensi.** Buka [Matriks Literatur](matrix/index.md) untuk paper kalibrasi, lalu [Referensi](referensi.md) untuk DOI lengkap.

---

## Navigasi ringkas

* [Perencanaan](perencanaan.md): PICOC, RQ, query, kriteria IC/EC, instrumen QA, dan status sumber.
* [Progres](progres.md): Pemilik tunggal angka korpus dan diagram PRISMA.
* [Matriks Literatur](matrix/index.md): Matriks paper studi kalibrasi beserta penampil interaktif.
* [Studi Tereksklusi](excluded.md): Log studi tereksklusi tahap L1 per kriteria EC.
* [Jejak Audit](audit.md): Catatan audit teknis dan log testing recall.
* [Gap](gap.md): Status kesenjangan riset (OPEN).
* [Kalibrasi L2 dan Adjudikasi (pilot.md)](pilot.md): Paket kalibrasi paper dan ruang adjudikasi.
* [Referensi](referensi.md): Daftar pustaka berformat BibTeX dan tautan DOI.
